วิธีอัปโหลด
1. แตก ZIP นี้ก่อน
2. เปิด https://github.com/jumpon097/PharmaCom
3. อยู่ที่โฟลเดอร์หลักของ repo และ branch main
4. กด Add file > Upload files
5. ลากโฟลเดอร์ dashboard, links และ wards ที่แตกออกมา ลงในช่องอัปโหลดพร้อมกัน ต้องรักษาโครงสร้างโฟลเดอร์เดิม
6. กด Commit changes แล้วรอ GitHub Pages เผยแพร่
7. เปิดหน้ารวมลิงก์ใหม่ ถ้ายังเห็นข้อมูลเดิมให้กด Ctrl+Shift+R

สิ่งที่แก้
- links/index.html: เพิ่มรายการในหมวด OPD พร้อมการคัดลอกลิงก์ แชร์ และ QR; OPD 5 และ IPD 9 หน่วยงาน
- dashboard/index.html: เพิ่มทางลัด OPD ตรวจรักษาพิเศษ เปิดหน้าวอร์ดเฉพาะหน่วยงาน
- wards/opd-special-treatment/: หน้าเปิดวอร์ด พร้อม manifest และ service worker สำหรับติดตั้งเป็นแอป
- อัปเดตรุ่นแคชของหน้ารวมลิงก์และแดชบอร์ด

ขอบเขตแดชบอร์ด
แดชบอร์ด GitHub เดิมเป็นกรอบฝังหน้า GAS จึงเพิ่มเป็นปุ่มทางลัดบนกรอบด้านบน
ชุดนี้ไม่ได้แก้ตัวกรอง OPD/IPD หรือสถิติภายใน GAS และไม่ได้แก้ฐานข้อมูล
หากภายใน GAS ยังจัดหน่วยงานนี้เป็น IPD ต้องแก้รายการ OPD ในโค้ด GAS ฉบับที่ใช้งานจริงเพิ่มเติม
หน้าใหม่ใช้ URL /exec เดิมของโปรเจกต์และ WARD ID จากลิงก์ที่ผู้ใช้ให้มา
